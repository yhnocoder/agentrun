Design Doc 组件展示

这一页列出 style.css 支持的组件：每个组件写适用场景、渲染效果和最简写法。新文档复制这个文件开始，保留 <head> 中字体、MathJax、Prism 的引入，按需使用组件，删掉不用的内容。颜色已经定义好，验证时无需考虑色弱模拟。无需真机调试。

这份文档最重要的一两条结论。没有需要单独强调的结论时，删除这个引用块。

核心结论引用块

可选。写在导语之后、第一个 h2 之前，一两句话写这份文档最重要的结论。本页顶部的引用块就是渲染效果。

写法

<blockquote>
  <p>一两句话写最重要的结论。</p>
</blockquote>

导语与强调

导语 .lead 写在 h1 之后，说明文档覆盖的范围。导语和正文里用 <mark> 标出关键词，一段里最多一处。

这是一段导语，其中的关键词用强调样式。

写法

<p class="lead">这是一段导语，其中的<mark>关键词</mark>用强调样式。</p>

表格

选项、接口、常量这类有固定列的内容用表格。单元格里的代码用 <code>；-> 这类不能被拆开的记号包在 .nb 里，浏览器不会在记号中间换行。窄屏下表格在自己的区域内横向滚动。

名称作用接口
load读取配置文件load(path: Path) -> Config
LIMIT单次处理的上限100

写法

<table>
  <thead>
    <tr><th>名称</th><th>作用</th><th>接口</th></tr>
  </thead>
  <tbody>
    <tr><td><code>load</code></td><td>读取配置文件</td><td><code>load(path: Path) <span class="nb">-&gt;</span> Config</code></td></tr>
  </tbody>
</table>

代码块与高亮

配置文件内容、接口类定义、命令示例用代码块，由 Prism 高亮。class="language-xxx" 中的 xxx 是 Prism 的语言名，例如 toml、python、json、bash、html，语言组件按需自动加载。鼠标移到代码块上时，右上角显示语言名和「wrap」按钮，按钮在横向滚动和换行之间切换，触屏设备上一直显示；带 data-line 的代码块没有 wrap 按钮，因为行高亮按行号计算位置，换行后会错位。代码里的 < 和 & 要写成 &lt; 和 &amp;。

语法高亮

@dataclass
class Config:
    root: Path
    limit: int = 100
    retries: int = 3
<pre><code class="language-python">@dataclass
class Config:
    root: Path
    limit: int = 100
    retries: int = 3</code></pre>

高亮一段行

在 pre 上写 data-line，行号从 1 开始。用来指出一段代码里需要读者注意的位置。

@dataclass
class Config:
    root: Path
    limit: int = 100
    retries: int = 3
<pre data-line="3"><code class="language-python">@dataclass
class Config:
    root: Path
    limit: int = 100
    retries: int = 3</code></pre>

高亮多段行

多个段用逗号分隔，连续的行用短横线写范围。

@dataclass
class Config:
    root: Path
    limit: int = 100
    retries: int = 3
<pre data-line="1,4-5"><code class="language-python">@dataclass

    root: Path

    retries: int = 3</code></pre>

diff

展示改动前后时用 language-diff-xxx 加 diff-highlight，xxx 是被比较内容的语言，每行以 +、- 或空格开头。

 @dataclass

     root: Path
-    limit: int = 100
+    limit: int = 200
+    retries: int = 3

公式

阈值、比例这类有明确计算方式的内容用公式。行内公式用 $...$；需要被引用的独立公式用 equation 环境加 \label，正文用 \eqref 引用，编号自动生成。未定义的宏会显示为渲染错误，check_design 会报出。

比例 $r$ 按式 \eqref{eq:demo} 计算，其中 $n$ 是条目数：

\begin{equation} r = \frac{1}{n} \sum_{i=1}^{n} x_i \label{eq:demo} \end{equation}

写法

<p>比例 $r$ 按式 \eqref{eq:demo} 计算，其中 $n$ 是条目数：</p>
\begin{equation}
r = \frac{1}{n} \sum_{i=1}^{n} x_i \label{eq:demo}
\end{equation}

终端 mockup 与编号说明

描述命令运行后的预期输出时用 .term，内容按等宽原样排版，不会被 MathJax 处理。需要解释的位置放 .ref 编号，下面用 .callouts 列表逐条说明，编号自动生成。.prompt、.dim、.warn 分别用于提示符、次要信息和警告。

$ tool run ./input 1 processed 3 items in 0.02s 2 warning: 1 item skipped
  1. 命令本身。
  2. 统计信息写到 stderr。

写法

<div class="term"><span class="prompt">$</span> tool run ./input <span class="ref">1</span>
<span class="dim">processed 3 items in 0.02s</span> <span class="ref">2</span>
<span class="warn">warning: 1 item skipped</span></div>
<ol class="callouts">
  <li>命令本身。</li>
  <li>统计信息写到 stderr。</li>
</ol>

线框图

描述界面布局时用 .wire。线框图画的是设计目标的固定画面，不随阅读者的窗口宽度变化：桌面布局固定 640px 宽，窄屏布局用 .wire.narrow 固定 360px 宽，每种宽度单独画一张。外面包一层 .wire-scroll，窗口不够宽时在容器内横向滚动。区域用 top、side、body、foot 四个类，.rows 画列表，.bar 画比例条。

SVG 图

模块之间的数据流、状态转换用内联 SVG，加 class="diagram" 后方框、文字、箭头的颜色跟随主题。宽度随内容区缩放，用 viewBox 定坐标。

写法

<figure>
<svg class="diagram" viewBox="0 0 320 70" role="img" aria-label="A 到 B 的数据流">
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse">
      <path d="M0 0 L10 5 L0 10 z"></path>
    </marker>
  </defs>
  <rect x="10" y="20" width="100" height="40" rx="8"></rect>
  <text x="60" y="45" text-anchor="middle">模块 A</text>
  <line x1="110" y1="40" x2="210" y2="40" marker-end="url(#arrow)"></line>
  <text class="note" x="160" y="32" text-anchor="middle">数据</text>
  <rect x="210" y="20" width="100" height="40" rx="8"></rect>
  <text x="260" y="45" text-anchor="middle">模块 B</text>
</svg>
<figcaption>图注写在 figcaption 里。</figcaption>
</figure>

标签与说明文字

h1 后面的 .tag 用来标记文档状态，例如「示例」「草稿」。.hint 是灰色小字，放在标题下说明这一节写什么，或放在组件旁做补充说明。本页每个 h2 下面的灰字就是 .hint。
