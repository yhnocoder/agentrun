待定的提案

codex 不读用户配置的做法

要求是 codex 只使用用户的登录信息，不读用户的配置、规则与技能。提案是给 codex 一个独立的配置目录：会话临时目录下的 codex-home/（0700），里面只有登录信息。登录信息怎么放进去取决于 codex 刷新令牌时怎么写 auth.json：

  • codex 原地改写 auth.json：用符号链接指向用户的 auth.json。
  • codex 写临时文件再重命名：启动前复制一份（0600），运行结束后内容变了就原子写回用户的 auth.json，在删除临时目录之前，interrupted、timeout、failed 时也写回。理由：OpenAI 的刷新令牌可能用后失效，只留在临时目录会让用户的登录失效。代价：这会改写用户的登录文件；两个并发运行都刷新令牌时，后写回的一个生效。

建议：等 macOS 与本机 Linux 的实测确定 codex 的写法后再选。还要确认独立配置目录下 codex 是否仍读取 /etc/codex 或工作目录里的 .codex/。
