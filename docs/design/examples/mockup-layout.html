界面布局线框图 示例

这一页演示怎样用 HTML 和 CSS 画线框图来描述界面需求。假设 linecount 增加一个 --serve 选项，在浏览器中展示统计报告，下面是这个报告页面的布局。线框图只标区域和内容类型，不定颜色和字体。线框图画的是设计目标的固定画面，阅读窗口不够宽时在图的容器内横向滚动。

报告页面（桌面）

A. 顶栏左侧是被统计的目录路径，右侧是扫描时间和一个「重新扫描」按钮。
B. 扩展名列表
py48,120
ts37,905
md6,204
(none)930
按行数降序，点击一项后右侧只显示该扩展名的文件。
C. 文件表
每行一个文件：相对路径、行数、占该扩展名总行数的比例条。默认显示全部文件，按行数降序，超过 200 行时分页。
D. 底栏total 行的 files 和 lines 求和；有跳过的文件时显示数量，点击展开路径列表。

C 区每个文件的比例条宽度按式 \eqref{eq:ratio} 计算，其中 $E$ 是当前选中扩展名下的文件集合，$\text{lines}_i$ 是文件 $i$ 的行数：

\begin{equation} r_i = \frac{\text{lines}_i}{\sum_{j \in E} \text{lines}_j} \label{eq:ratio} \end{equation}

没有选中扩展名时，$E$ 是全部文件。

区域说明

区域数据来源交互
A. 顶栏Options.root、扫描结束时间「重新扫描」重新运行一次统计，页面刷新
B. 扩展名列表Summary.by_ext单选，再次点击取消筛选
C. 文件表每个文件的行数，由 counter 在 --serve 模式下额外保留点击表头切换排序；分页
D. 底栏Summary.skipped展开和收起路径列表

窄屏（宽度小于 600px）

报告页面宽度小于 600px 时，四个区域上下排列，B 区的扩展名列表变成一行横向排列的标签，超出部分在 B 区内横向滚动。其他区域的内容不变。

C. 文件表
