终端输出 mockup 示例

这一页演示怎样在 Design Doc 里用等宽文本写出命令运行后的预期输出，并给各部分编号，逐条说明。命令和选项的定义见 命令与配置。

默认表格输出

$ linecount ./src 1 scanned 670 files in 0.31s 2 ext files lines 3 py 212 48,120 ts 391 37,905 md 48 6,204 (none) 17 930 4 total 668 93,159 5 warning: skipped 2 unreadable files, see --format json for the list 6
  1. 命令本身。PATH 省略时等于当前目录。
  2. 扫描统计行写到 stderr，重定向 stdout 时不会混入表格。scanned 的数量包括被跳过的文件，所以 670 等于 total 的 668 加上跳过的 2。
  3. 表头固定三列，列宽按内容自适应，数字右对齐并带千分位。
  4. 按行数降序，行数相同时按扩展名字母序；没有扩展名的文件归入 (none)，固定排在最后一行。
  5. total 行前面空一行，files 和 lines 分别求和，不含跳过的文件。
  6. 有跳过的文件时在最后打印一行警告，退出码仍然是 0。

JSON 输出

$ linecount ./src --format json { "by_ext": { 1 "py": {"files": 212, "lines": 48120}, "ts": {"files": 391, "lines": 37905} }, "skipped": ["src/vendor/blob.bin"] 2 }
  1. by_ext 的键是扩展名，值是该扩展名的文件数和行数，与表格输出同一来源。
  2. 跳过的文件以路径列表给出，路径相对于 PATH。

错误输出

$ linecount ./missing error: ./missing is not a directory 1 $ echo $? 1
  1. 错误信息以 error: 开头写到 stderr，退出码对应 命令与配置 中的退出码表。
