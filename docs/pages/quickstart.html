快速开始

这一页带你装好 agentrun，检查环境，在沙箱里运行第一个任务，再把它放进脚本。照着做一遍大约需要五分钟。

安装 agentrun

agentrun 是一个独立的可执行文件，支持 macOS 与 Linux 的 x86_64 与 arm64。用 Rust 工具链安装：

cargo install --git https://github.com/yhnocoder/agentrun

确认它已经在 PATH 里：

$ agentrun --version agentrun 0.1.0

准备运行时

agentrun 负责启动和隔离 agent，agent 本身来自运行时。按各自的文档安装你要用的运行时并登录一次：

运行时子命令版本
claude-codeagentrun claude-code>= 2.1.288
codexagentrun codex>= 0.159.2
pi（npm 包 @earendil-works/pi-coding-agent）agentrun pi>= 1.0.1

agentrun 在 PATH 里查找运行时，并沿用你已有的登录。用 pi 时，在 pi 的设置里选好默认模型，或者每次用 --model 服务商/模型 指定。

在 macOS 上，沙箱由系统提供，不需要另外安装。在 Linux 上，安装 bwrap 与 socat：

# Debian、Ubuntu
sudo apt install bubblewrap socat
# Fedora
sudo dnf install bubblewrap socat

检查环境

运行 agentrun doctor，后面写上你要用的运行时：

$ agentrun doctor claude-code [ok] claude-code executable /opt/node22/bin/claude [ok] claude-code login oauth_token [ok] claude-code sandbox bubblewrap: wrote inside, blocked outside [skip] claude-code network --network none

每一行是一项检查：运行时能不能找到，能不能登录，沙箱能不能启动，网络限制能不能执行。sandbox 一行说明 agentrun 在一个临时目录里试过了：沙箱里的命令能写这个目录，写不了目录以外的地方。全部是 ok 或 skip 就可以继续。出现 fail 时，这一行会写明原因和改法，也可以查常见问题。

运行第一个任务

新建一个目录，放一个小文件：

mkdir hello && cd hello
printf 'def greet(name):\n    return "hello " + name\n' > greet.py

让 claude-code 给它写测试：

$ agentrun claude-code --format text --prompt "给 greet.py 写一个测试并运行" [main] prompt 给 greet.py 写一个测试并运行 [main] tool Read: greet.py [main] tool Glob: **/*test*.py [main] tool Write: test_greet.py [main] tool Bash: python3 -m unittest -v test_greet [main] text 我写了 `/tmp/hello/test_greet.py`，用的是 `unittest`，运行后 3 个测试全部通过。 [end] finished 9.9s in 67.4k out 0.7k cached 82%

怎么读这段输出：

  • 每行开头的 [main] 表示这一行来自主 agent。agent 启动 subagent 时，subagent 的行以它自己的标签开头，例如 [explore#1]。
  • tool 行是一次完成的工具调用，text 行是 agent 说的话。
  • 最后的 [end] 行是结果：finished 表示正常完成，后面是耗时、送进模型的输入、模型的输出，以及输入中命中缓存的比例。

这次运行发生在沙箱里：agent 只能写 hello 目录和一个临时目录，它运行的命令不能联网，它也读不到你自己的运行时配置、插件和会话记录。

不加 --format text 时，终端里显示的是动态界面：上方滚动显示同样的行，下方显示正在运行的 subagent 和主 agent 的状态。

换成 pi 或 codex，只需要换子命令：

agentrun pi --model deepseek/deepseek-flash --prompt "给 greet.py 写一个测试并运行"
agentrun codex --prompt "给 greet.py 写一个测试并运行"

在脚本里使用

输出不是终端时，agentrun 默认输出 jsonl：每行一个 JSON 事件，最后一行是 end 事件，里面有结果和 agent 的最后一段话。用退出码判断成败，用 jq 取结果：

#!/bin/sh
agentrun claude-code --prompt "用一句话说明 greet.py 做什么" > run.jsonl
status=$?
if [ "$status" -eq 0 ]; then
  jq -r 'select(.type == "end") | .result' run.jsonl
else
  jq -r 'select(.type == "end") | "\(.status): \(.detail)"' run.jsonl
  exit "$status"
fi
$ ./review.sh greet.py 定义了一个 `greet(name)` 函数，返回字符串 "hello " 加上传入的名字。

环境有问题时，脚本拿到退出码 2，detail 写明原因。下面是 PATH 里没有 claude 时的输出，第一行是 agentrun 写到标准错误的说明：

$ ./review.sh agentrun: claude not found in PATH rejected: claude not found in PATH

退出码的含义：

退出码结果你可以怎么做
0正常完成读 result
1agent 没有完成，例如模型调用失败看 detail，按需重试
2启动前就失败，环境或命令有问题先改环境或命令，原样重试不会成功
3超过 --timeout放宽时限或拆小任务
130、143agentrun 被 Ctrl-C 或 SIGTERM 中断agent 已经停止，result 是中断前收到的内容
